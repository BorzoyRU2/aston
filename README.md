# Aston Java Project

## Наш итоговый проект!

Данный проект представляет собой учебное Java-приложение, разработанное в рамках обучения и практики по основам Javа.

## Структура проекта

```text
src
 ├── main
 │    └── java
 │         └── org.example
 │              ├── filler
 │              ├── model
 │              ├── search
 │              ├── sort
 │              ├── validation
 │              └── writer
 │
 └── test
      └── java
           └── org.example
```
## Сборка проекта

### Клонирование репозитория

```bash
git clone https://github.com/BorzoyRU2/aston.git
```

### Переход в директорию проекта

```bash
cd aston
```

### Сборка проекта

```bash
mvn clean install
```

### Запуск проекта

```bash
mvn exec:java
```

## Тестирование

Для запуска тестов:

```bash
mvn test
```
